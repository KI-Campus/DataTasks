# What are in this folder?
Here're the datasets in this repository:
1. MasterList_Update.csv:a matched list of email domains and institutions, used for HEI analysis.
2. all_email_provider_domains.txt: commercial email providers, e.g., gmail, gmx, etc.  ⚠️DISCLAIMER: do not cover ALL commercial domains, original [dataset](https://github.com/jacksonbarreto/Higher-Education-Institutions-in-Germany-Dataset/blob/main/data%20source/german-heis.csv)
3. de_hei_region_drupal.csv: a matched list of all German HEIs and their states.
4. germain-heis.xlsx: a list German HEIs, HEI names are modified based on the [original list](https://github.com/jacksonbarreto/Higher-Education-Institutions-in-Germany-Dataset/blob/main/data%20source/german-heis.csv)
5. german_states.geojson: geojson of the German map - for Chropleth map
6. world.geojson: geojson of the world map - for Chropleth map
7. world_universities_and_domains.json - university domain for the universities around the globe, standardised German HEI names as in the german-heis.xlsx. Here is the [JSON data set](https://github.com/Hipo/university-domains-list?utm_source=chatgpt.com)
